# Encore

[English README](README.en.md)

一个以剧场体验为灵感的专注计时工具。选择或创建一场“演出”，取票入场，在专注结束后收藏属于自己的票根。

## 版本说明

| 分支 | 用途 |
| --- | --- |
| `main` | 网页版：适配桌面与移动浏览器，保留完整的网页体验与既有剧目。 |
| `codex/xhs-minitool` | 小红书小工具版：采用离线、自包含的静态资源结构，适配小工具容器。 |

两个版本分别维护，互不自动影响。

## 网页版功能

- 探索预设剧目，或创建并收藏自定义剧目
- 自由填写 1–240 分钟的专注时长、地点、中场和座位
- 模拟取票机打印并推出入场票根
- 专注计时、暂停、提前离场与离开剧场超时判定
- 有中场的演出可暂存本场，之后从首页倒计时卡片继续下半场
- 中场结束前未返回或直接离开时，票根仅保留上半场的实际专注时长
- 在票夹中浏览全部记录，为完成票根签名，并保存为图片
- 中英文界面切换；票根会保留打印时的语言

## 本地预览

这是一个不依赖构建步骤的静态网站。用任意本地静态服务器打开项目根目录即可，入口文件是 `index.html`。

常用页面：

- `index.html`：开场与进入剧院
- `home.html`：探索剧目、自定义剧目、我的票夹
- `ticket.html`：打印入场票根
- `focus.html`：专注与中场流程
- `tickets.html`：全部票根、签名与图片保存

## 本地数据

剧目、专注记录、未完成的中场状态和票根签名均只保存在浏览器当前设备的本地存储中，不会上传或共享。清除浏览器站点数据或使用“清空本地记录”后，这些内容将无法恢复。

## 小红书小工具

如需打包小红书版本，请切换至 `codex/xhs-minitool` 分支。该分支仅使用包内 HTML、CSS、JavaScript 与本地资源，避免依赖网络请求或外部服务。
